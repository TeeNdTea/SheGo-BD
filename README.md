# SheGo BD Frontend Prototype

Static HTML prototype exported from Stitch.

## Pages
- `index.html` — onboarding / verification (homepage)
- `onboarding.html` — same onboarding screen
- `dashboard.html` — SafePools dashboard
- `community-safety.html` — Community Safety / SOS

## Deploying on Vercel
If this folder is uploaded as the contents of a GitHub `Frontend` folder, set Vercel Root Directory to `Frontend` and deploy as a static site.

No build command is required. The prototype uses Tailwind CDN and Google Fonts.
